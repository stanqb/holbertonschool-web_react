# Holberton School - Web React

This repository contains projects and exercises focused on modern web development with React, TypeScript, and related technologies as part of the Holberton School curriculum.

## Repository Structure

The repository is organized into different directories, each covering specific topics and technologies:

- **TypeScript/**: Comprehensive TypeScript learning project covering interfaces, classes, advanced types, and namespace organization
- *(Additional directories will be added as the curriculum progresses)*

## Technologies Covered

- **TypeScript**: Static typing, interfaces, classes, namespaces, and advanced type systems
- **React**: Component-based architecture and modern JavaScript frameworks
- **Webpack**: Module bundling and build tools
- **Jest**: Testing framework for JavaScript and TypeScript
- **ESLint**: Code linting and quality assurance

## Getting Started

Each project directory contains its own README with specific setup instructions. Generally:

1. Navigate to the specific project directory
2. Install dependencies: `npm install`
3. Build the project: `npm run build`
4. Run tests: `npm test`
5. Start development: `npm run start-dev`

## Learning Objectives

This repository aims to provide hands-on experience with:

- Modern JavaScript and TypeScript development
- Component-based web application architecture
- Build tools and development workflows
- Testing methodologies
- Code quality and best practices

## Requirements

- **Node.js**: Latest LTS version recommended
- **npm**: Package manager for JavaScript
- **Modern browser**: For testing web applications
- **Code editor**: VS Code, vim, emacs, or similar
