# React Props

Second project of the Holberton React track, built on top of the **React intro** dashboard.
The goal is to break a monolithic `App.jsx` into small, reusable functional components and
to pass data between them through props.

## Learning Objectives

- How to create basic React components using functions
- How to reuse components
- How to pass properties (props) to components
- How to use Fragments
- When to use a `key` to improve a loop's performance

## Requirements

- Ubuntu 20.04 LTS, `node 20.x.x`, `npm 10.x.x`
- Allowed editors: `vi`, `vim`, `emacs`, `Visual Studio Code`
- All files end with a new line
- A `README.md` file is mandatory at the root of the project and in each task folder
- Jest installed globally: `npm install -g jest` (version `29.7.0`)
- No errors or warnings in the browser console, no lint errors, all unit tests passing

## Installation

```bash
cd task_0/dashboard
npm install
npm run dev
npm test
```
